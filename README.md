# Trekpad 🎒

Web-app voor trektochten in Europa (later wereldwijd): routes met schoonheid en moeilijkheidsgraad,
haalbaarheid per reisvorm (zonder auto / eigen auto / vliegen / vliegen + huurauto), kostenschatting,
live weer met kledingadvies en tips om elke route veilig te starten.

Alles zit in `index.html`. Online via GitHub Pages.
